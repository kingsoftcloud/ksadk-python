title: KsADK

---

**Kingsoft Cloud Agent Development Kit** builds, debugs, deploys, and observes
enterprise AI Agents. In 0.8.3, the trusted kernel closes concurrency, recovery,
and state-consistency boundaries; the Harness owns the execution lifecycle; and
pluggable Providers connect execution engines. Choose a project shape, then reuse
the same Studio, API, session, and event capabilities.

```bash
pip install -U "ksadk[all]"
```
