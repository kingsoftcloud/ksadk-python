title: KsADK
---

**Kingsoft Cloud Agent Development Kit** is a cloud-native framework to build, deploy, debug, and observe enterprise AI agents. Keep building business agents with Google ADK, LangGraph, LangChain, or DeepAgents, then use KsADK for a unified local runtime, browser debugging, OpenAI-compatible API, sandbox execution, OpenClaw / Hermes runtime launch paths, and observability.

```bash
pip install -U "ksadk[all]"
```
