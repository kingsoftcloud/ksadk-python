**Kingsoft Cloud Agent Development Kit** builds, debugs, deploys, and observes
enterprise AI Agents. Start by choosing the shape of your project; every path
then shares the local Web UI, OpenAI-compatible API, sessions, and observability.

```bash
pip install -U "ksadk[all]"
```
