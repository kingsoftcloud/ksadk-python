title: KsADK
---

**KsADK** (Kingsoft Cloud Agent Development Kit) is Kingsoft Cloud's runtime platform for AI agents. Keep building business agents with Google ADK, LangGraph, LangChain, or DeepAgents, then use KsADK for a unified local runtime, browser debugging, OpenAI-compatible API, sandbox execution, deployment, and observability experience.

```bash
pip install -U "ksadk[all]"
```
