---
title: KsADK
---

**KsADK**（Kingsoft Cloud Agent Development Kit）是金山云面向 AI Agent 的运行时平台。继续使用 Google ADK、LangGraph、LangChain 或 DeepAgents 编写业务 Agent，再用 KsADK 获得统一的本地运行、浏览器调试、OpenAI-Compatible API、沙箱执行、部署和可观测体验。

```bash
pip install -U "ksadk[all]"
```
