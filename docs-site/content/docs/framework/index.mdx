**Kingsoft Cloud Agent Development Kit** 用于构建、调试、部署和观测企业级 AI
Agent。先选择你的项目形态；所有路径随后都能复用同一套本地 Web UI、OpenAI
兼容 API、会话和可观测能力。

```bash
pip install -U "ksadk[all]"
```
