# Studio 配置收敛

状态：已实现；本次不变更版本号、不发布 PyPI。此文替代原下一版本待办。

## 用户入口与兼容

用户在 Studio 设置页完成模型凭证与云端连接配置，无需另建 `studio.env`。工作区统一保存到 `.agentkit/config.yaml`，使用 version/settings/secrets 三个字段；文件原子写入、权限 0600，并自动加入 `.gitignore`。凭证不进入设置 API 的返回值。

旧 `.agentkit/settings.yaml` 和 `.agentkit/secrets.env` 首次读取时迁移到新存储，原文件保留、不再更新。已有 `.env` 不自动改写。未知设置在合并保存时保留；损坏文件返回明确错误，避免静默清空。普通 CLI 也加载当前工作区的统一配置。

优先级：显式 `--env-file` > 工作区保存值 > 启动环境 > 工作区 `.env`。显式文件只影响本次进程，采用模型与云端字段白名单；显式 `--codex-proxy` 优先于保存值。设置页显示地址、账号来源和缺失字段。手动修改文件后请重启 Studio，使所有运行组件同步生效。

## 保存与账号切换

设置页补充控制面地址。设置 API 在没有活动运行时暂停插件接入，释放旧宿主，再保存配置、重建资源授权和默认云端网关，最后恢复接入。后续资源调用使用新凭据，重启后从工作区恢复。

切换 Access Key 必须同时提供匹配的 Secret Key；未填写新的 Account ID 时清除旧账号 ID。凭据留空保持现有值。非法地址或不完整账号切换不会覆盖已保存配置。平台连接的“配置完整”只表示必要配置齐备，真实权限仍由签名授权请求验证。

## 静态资源与开发安装

设置页“关于”展示服务实际提供的 JS/CSS 入口文件名，帮助比对构建哈希。editable 安装不编译静态资源，需执行 `make build-frontend` 后重启服务。wheel 打包必须携带该次构建产物。终端升级、旧服务重启与浏览器强制刷新的操作见中英文 Studio 使用指南。

## 验收范围

- 配置迁移、来源优先级、显式覆盖不落盘、文件权限、损坏文件保护、凭据合并与最新读取。
- 设置保存立即建立资源授权、切换账号释放旧宿主、活动运行拒绝更新、重启恢复。
- 设置 API 写入假凭据后，通过本地 HTTP fixture 完成真实签名授权请求，验证资源接入使用刚保存的凭据；该项不代表线上账号授权验收。
- 浏览器首次填写、保存并重新打开设置：来源正确，连接配置状态更新，AK/SK 不回显。
- 前端构建、现有前端契约测试和候选 wheel 内容核验。
