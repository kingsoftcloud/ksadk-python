# 端云评测一期开发记录

## 定位

端云评测集的唯一数据底座是 EvalSmith。`agent-eval` 提供产品 API、项目和身份上下文适配；KsADK 默认经 AICP/KOP 调用它，不再要求用户配置或传入 agent-eval 服务地址。

一期主链路：

```text
本地 EvalSet
  -> KsADK 解析、固定六列转换、DataPolicy 预检
  -> agentengine evalset preview/push
  -> AICP KOP PublishEvaluationSetSnapshot（AK/SK 签名）
  -> agent-eval -> EvalSmith Dataset 创建或原子 publish
  -> DatasetId + DatasetVersion
  -> .agentkit/evaluation-bindings/<path-hash>.yaml
  -> CLI / Studio 固定版本 pull 和评测
  -> 本地 EvalRunReport 关联 Dataset version 与 TargetSnapshot
```

## 已实现

- KsADK 把 `EvalSetVersion` 转换为固定六列 Dataset Snapshot：`case_id`、`turns`、`assertions`、`case_metadata`、`source_format`、`ksadk_content_digest`。
- `agentengine evalset preview` 输出完整待发布快照；`push` 一期只更新已有 Dataset。
- 首次发布必须显式传 `--dataset-id`；随后按文件路径复用本地 `CloudBinding`；显式另一个 ID 会在发布成功后切换绑定。
- 默认使用 `full_trace`，自动生成幂等键，不发送 `BaseVersion`；只有远端返回的 content digest、schema hash、行数都与本地一致，才原子写入 Binding。
- `agent-eval` 提供 `PublishEvaluationSetSnapshot`：首次创建和已有 Dataset publish 都由 EvalSmith 在单一事务中创建不可变版本。
- `evalset pull` 通过 `DescribeEvaluationSet` 分页读取确定的 `DatasetId + DatasetVersion` 并恢复本地 EvalSet。
- 云 Dataset 固定版本可作为 CLI 和 Studio 评测输入，`EvalRunSpec/Report` 记录 Dataset ID、version、schema hash 和 content digest。
- Studio 评测表单不再提供 Dataset version 数字输入；用户从 Catalog 选择带 `vN` 标记的不可变快照，版本和摘要由选项自动带入请求。
- Studio Target 表单按类型显示业务控件：A2A 使用“Agent 地址”，Local Source 使用“Agent 源码目录”，Studio Build 使用 Build 下拉框；后端仍统一接收 `TargetRef.kind/locator`。
- 未设置 `AGENT_EVAL_BASE_URL` 时，KsADK 通过 AICP KOP 发送 `PublishEvaluationSetSnapshot`、`DescribeEvaluationSet`、`ListEvaluationSet`，复用 `KSYUN_ACCESS_KEY`、`KSYUN_SECRET_KEY`、`KSYUN_ACCOUNT_ID` 和既有预发路由信号。

### Catalog 选择语义与故障诊断

- Studio 的 `Dataset source` 选项对用户显示为 `Cloud Dataset`；Dataset version 不提供单独输入，版本仍由不可变快照选项自动带入。
- `ListEvaluationSet` 使用 `DatasetType=Manual` 获取产品评测集，再读取固定版本快照并校验 KsADK digest；不能使用 `Column=ksadk_content_digest` 代替类型筛选，否则会误命中 OnlineEval 或其他包含同名列的数据集，最终目录为空。
- Cloud Dataset 目录请求失败时，Studio 在字段下显示后端返回的错误；只有请求成功但没有符合不可变快照契约的数据时，才显示空列表。

## 当前边界

- 已支持：预览、更新已有评测集、Binding 复用/切换、固定版本 pull、固定云版本参与 CLI/Studio 评测和本地 Report 追溯。
- 一期 CLI 不暴露创建 Dataset 入口；用户先在 Studio/平台准备已有 Dataset，再由 CLI 更新。
- 未支持：Studio 上传/Binding 管理 UI、云端 Experiment、Report/evidence 上传、Trace 候选回流、完整 RBAC/审计/留存闭环。
- EvalSmith 尚未持久化完整幂等结果；网络超时后 KsADK 不能自动安全重试。
- EvalSmith 尚无条件 publish，故 KsADK 不暴露也不发送 `BaseVersion`，不以客户端先读后写伪造并发安全。
- EvalSet 顶层 `metadata` 尚未完整进入 EvalSmith Dataset 主模型。
- 上线前必须在 KOP 预发和线上登记 `PublishEvaluationSetSnapshot`；在 Action 未登记时，KOP 会明确返回 `InvalidActionOrVesion`，客户端不会静默回退到直连。

本轮没有调整 Studio UI，也没有提交或发布代码。新增能力保持 V1 兼容：

- `runtime.maxTotalTokens`：在 usage 报告总 token 时做预算比较；没有 usage 时为 `UNAVAILABLE`。
