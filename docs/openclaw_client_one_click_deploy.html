开发者友好，只为极简落地

用最清晰的命令行实现最复杂的集群拓扑操作。部署、扩繁、回收，一气呵成。

bash - launch
# 0. 环境准备：安装 Python SDK 与核心引擎 CLI
pip install -U ksadk
# 验证底座工具链版本
agentengine version

# 1. 一键保苗部署 (初始化)
agentengine init my-openclaw -f openclaw
cd my-openclaw

# 执行首发上线
agentengine openclaw deploy

# 2. 高峰瞬间扩展虾群 (想养几只养几只)
agentengine openclaw deploy --name peak-01
agentengine openclaw deploy --name peak-02
# 随时追踪整体舰队状态
agentengine openclaw status

# 3. 一键回塘 (低峰回收，极致控本)
agentengine openclaw list
agentengine openclaw delete ar-xxxx -y
agentengine config
# 零感全局配置：一次敲定，全项目生效（替代低效的 .env）
❯ agentengine config --global \
--set KSYUN_ACCESS_KEY=YOUR_AK \
--set KSYUN_SECRET_KEY=YOUR_SK \
--set OPENAI_API_KEY=YOUR_LLM_KEY

✔ [Global] Successfully updated agentengine settings.
❯ cat ~/.agentengine/settings.json
{
  "global_ksyun_ak": "YOUR_AK",
  "global_ksyun_sk": "********",

}
