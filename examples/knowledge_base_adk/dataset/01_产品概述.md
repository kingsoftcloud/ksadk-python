# AgentEngine 产品概述

## 什么是 AgentEngine

AgentEngine（又称 KsADK）是金山云推出的一站式 AI Agent 开发部署工具套件。它支持开发者使用 LangChain、LangGraph 和 Google ADK 三种主流框架构建智能体应用，并提供从本地开发到云端部署的完整链路。

## 核心特性

- **多框架支持**：同时兼容 LangChain、LangGraph 和 Google ADK，自动检测框架类型
- **一键部署**：支持代码模式（Code Mode）和容器模式（Container Mode）两种部署方式，一条命令即可部署到金山云 Serverless 平台
- **内置记忆体**：支持短期记忆（Session 管理）和长期记忆（跨 Session 检索），通过环境变量配置即可启用
- **知识库集成**：支持接入金山云 AICP 知识库服务，Agent 自动获得 RAG 检索能力
- **可观测性**：集成 Langfuse 和 OpenTelemetry，提供端到端的 Agent 运行链路追踪
- **MCP 支持**：支持 Model Context Protocol，可接入外部工具服务

## 适用场景

1. 企业智能客服 - 基于知识库的自动问答
2. 数据分析助手 - 连接数据库和 BI 工具的分析 Agent
3. 多 Agent 协作 - 旅行规划、代码生成等复杂任务
4. 内部办公助手 - 集成企业内部系统的自动化流程

## 版本信息

当前最新版本为 v0.2.0，支持 Python 3.10 及以上版本。
