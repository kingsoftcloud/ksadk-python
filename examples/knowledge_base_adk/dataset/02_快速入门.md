# AgentEngine 快速入门指南

## 安装

使用 pip 安装 AgentEngine：

```bash
# 基础安装
pip install ksadk

# 安装 ADK 支持
pip install ksadk[adk]

# 安装知识库支持
pip install ksadk[kb]

# 安装全部依赖
pip install ksadk[all]
```

## 创建第一个 Agent

### 1. 初始化项目

```bash
agentengine init my_agent -f adk
```

这会创建一个标准的 ADK Agent 项目模板。

### 2. 配置环境变量

在项目根目录创建 `.env` 文件：

```
OPENAI_API_KEY=your_api_key
OPENAI_API_BASE=http://kspmas.ksyun.com/v1
MODEL_NAME=deepseek-v3.2
```

### 3. 编写 Agent

编辑 `agent.py`：

```python
from google.adk.agents import Agent
from google.adk.models.lite_llm import LiteLlm

model = LiteLlm(model="openai/deepseek-v3.2")

root_agent = Agent(
    name="my_assistant",
    model=model,
    description="我的第一个智能助手",
    instruction="你是一个友好的智能助手，用中文回复用户的问题。",
    tools=[],
)
```

### 4. 本地运行

```bash
# 交互模式（TUI 界面）
agentengine run . --interactive

# API 服务模式
agentengine run .
# 然后访问 http://localhost:8080/docs

# Web UI 模式
agentengine web .
```

### 5. 部署到云端

```bash
# 配置云凭证
export KSYUN_ACCESS_KEY=your_ak
export KSYUN_SECRET_KEY=your_sk

# 一键构建并部署
agentengine launch . --target serverless
```
