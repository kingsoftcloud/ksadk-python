# 知识库集成配置指南

## 概述

AgentEngine 支持接入金山云 AICP 知识库服务，为 Agent 提供 RAG（检索增强生成）能力。配置完成后，Agent 在对话中可以自动检索知识库内容，基于企业私有数据回答用户问题。

## 前置条件

1. 拥有金山云账号，并开通 AICP 服务
2. 在 AICP 控制台创建知识库，并上传文档（支持 PDF、Word、Markdown、TXT、HTML 等格式）
3. 获取知识库 ID（DatasetId）
4. 获取 AK/SK 访问凭证

## 环境变量配置

在项目根目录的 `.env` 文件中添加以下配置：

### 必填参数

```bash
# 知识库 ID — 设置后即自动启用知识库能力
KSADK_KB_DATASET_ID=your-knowledge-base-id

# 认证凭证（复用金山云 AK/SK）
KSYUN_ACCESS_KEY=your_access_key
KSYUN_SECRET_KEY=your_secret_key
```

### 可选参数

```bash
# API 区域，默认 cn-north-vip1
KSADK_KB_REGION=cn-north-vip1

# API 端点（外网），默认 aicp.api.ksyun.com
KSADK_KB_ENDPOINT=aicp.api.ksyun.com

# 协议，默认 https
KSADK_KB_SCHEME=https

# 返回结果数，默认 5
KSADK_KB_TOP_K=5

# 检索方法，默认 intelligence_search
KSADK_KB_SEARCH_METHOD=intelligence_search

# 分数阈值（设置后自动启用阈值过滤）
KSADK_KB_SCORE_THRESHOLD=0.5

# 重排序开关，默认 false
KSADK_KB_RERANKING_ENABLE=false

# 知识库专用 AK/SK（可选，未设置时回退到 KSYUN_ACCESS_KEY / KSYUN_SECRET_KEY）
# KSADK_KB_ACCESS_KEY=your_kb_specific_ak
# KSADK_KB_SECRET_KEY=your_kb_specific_sk
```

### 内网环境配置

如果在金山云内网环境中部署，建议使用内网端点以获得更低延迟和更稳定的连接：

```bash
KSADK_KB_ENDPOINT=aicp.inner.api.ksyun.com
KSADK_KB_SCHEME=http
```

## 使用方式

### 方式一：自动注入（ADK 框架推荐）

只需配置环境变量，无需修改 Agent 代码。AgentEngine 的 ADKRunner 会自动检测 `KSADK_KB_DATASET_ID` 环境变量，初始化知识库客户端，并将 `search_knowledge_base` 工具注入到 Agent 中。

```python
# agent.py - 不需要任何知识库相关代码
from google.adk.agents import Agent

root_agent = Agent(
    name="my_agent",
    model=model,
    instruction="当用户提问时，使用 search_knowledge_base 工具检索知识库。",
    tools=[],  # search_knowledge_base 会被自动注入
)
```

运行时只需确保环境变量已设置：

```bash
agentengine run .
```

### 方式二：显式导入

如果需要更明确的控制，可以在 Agent 代码中显式导入知识库工具：

```python
from google.adk.agents import Agent
from ksadk.knowledge_base.adk_tool import search_knowledge_base

root_agent = Agent(
    name="my_agent",
    model=model,
    instruction="当用户提问时，使用 search_knowledge_base 工具检索知识库。",
    tools=[search_knowledge_base],
)
```

### 方式三：LangChain / LangGraph

```python
from ksadk.knowledge_base.langchain_tool import search_knowledge_base

tools = [search_knowledge_base]
```

### 方式四：直接调用客户端（用于调试或自定义场景）

```python
from ksadk.knowledge_base.client import KnowledgeBaseClient

# 从环境变量创建客户端
kb = KnowledgeBaseClient.from_env()

# 检索
results = kb.search("如何配置知识库？", top_k=3)
for r in results:
    print(f"[{r.score:.3f}] {r.document_name}: {r.content[:100]}")
```

## 检索参数说明

| 参数 | 环境变量 | 说明 | 默认值 |
|------|----------|------|--------|
| DatasetId | `KSADK_KB_DATASET_ID` | 知识库 ID | 必填 |
| Query | — | 检索关键词，由 Agent 自动传入 | — |
| TopK | `KSADK_KB_TOP_K` | 返回结果数量 | 5 |
| SearchMethod | `KSADK_KB_SEARCH_METHOD` | 检索方法 | intelligence_search |
| ScoreThreshold | `KSADK_KB_SCORE_THRESHOLD` | 分数阈值，设置后自动启用过滤 | 不启用 |
| RerankingEnable | `KSADK_KB_RERANKING_ENABLE` | 是否启用重排序 | false |

## 部署注意事项

部署时，`.env` 文件中的环境变量会自动传递到 Serverless 运行环境。知识库相关的配置变量也会被正确传递，确保云端 Agent 具备与本地一致的知识库检索能力。

如果部署到金山云内网环境，将端点切换为内网地址：

```bash
KSADK_KB_ENDPOINT=aicp.inner.api.ksyun.com
KSADK_KB_SCHEME=http
```

## 常见问题

**Q: 知识库检索不到结果怎么办？**
A: 检查知识库中的文档状态是否为 completed，确认文档已完成索引。同时检查 Query 关键词是否与文档内容相关。可以在 AICP 控制台的知识库管理页面查看文档索引状态。

**Q: 如何提高检索准确率？**
A: 可以尝试以下方式：
1. 启用重排序功能：设置 `KSADK_KB_RERANKING_ENABLE=true`
2. 增加候选结果数：调大 `KSADK_KB_TOP_K` 参数
3. 优化文档切片策略：在 AICP 控制台调整文档分段方式
4. 设置分数阈值过滤低质量结果：`KSADK_KB_SCORE_THRESHOLD=0.5`

**Q: 可以同时使用多个知识库吗？**
A: 当前版本通过环境变量支持配置一个知识库。如需多知识库支持，可以在代码中手动创建多个 `KnowledgeBaseClient` 实例，分别传入不同的 `dataset_id`。

**Q: 自动注入和显式导入有什么区别？**
A: 功能完全一致。自动注入是零代码方案，适合快速上手；显式导入给开发者更多控制权，适合需要自定义工具列表的场景。如果 Agent 已显式添加了 `search_knowledge_base` 工具，ADKRunner 不会重复注入。

**Q: 内网和外网端点有什么区别？**
A: 内网端点 (`aicp.inner.api.ksyun.com`) 走金山云内网通道，延迟更低、带宽更稳定，推荐在金山云服务器上使用。外网端点 (`aicp.api.ksyun.com`) 适合本地开发和非金山云环境。
