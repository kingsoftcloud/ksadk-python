# Agent 记忆体配置指南

## 概述

AgentEngine 提供两层记忆体系，帮助 Agent 在对话中保持上下文、跨会话记住用户信息：

- **短期记忆（Short-term Memory）**：管理单次会话中的对话历史
- **长期记忆（Long-term Memory）**：跨会话持久化和检索用户信息

## 短期记忆配置

短期记忆负责 Session 的创建、存储和检索。

### 环境变量

```bash
KSADK_STM_BACKEND=local           # 后端类型: local / sqlite / database
KSADK_STM_DB_PATH=/tmp/sessions.db  # SQLite 数据库路径（sqlite 模式）
KSADK_STM_DB_URL=sqlite:///...      # 数据库连接 URL（database 模式）
```

### 后端选择

| 后端 | 说明 | 适用场景 |
|------|------|----------|
| local | 内存存储 + SQLite | 本地开发、调试 |
| sqlite | SQLite 持久化 | 单机部署、数据需持久化 |
| database | 远程数据库 | 生产环境、多实例部署 |

## 长期记忆配置

长期记忆负责跨 Session 的信息持久化和语义检索。当用户告诉 Agent 个人信息或偏好时，Agent 可以在新会话中记住这些内容。

### 环境变量

```bash
KSADK_LTM_BACKEND=local           # 后端类型: local / http
KSADK_LTM_HTTP_URL=https://...     # 远程记忆服务地址（http 模式）
KSADK_LTM_HTTP_TOKEN=sk-xxx        # 认证 Token（http 模式）
KSADK_LTM_TOP_K=5                  # 检索返回条数
```

### 工作原理

1. Agent 对话结束后，用户消息被提取并保存到长期记忆后端
2. 新会话开始时，Agent 使用 `load_memory` 工具检索历史记忆
3. 检索到的记忆作为上下文注入到 Agent，帮助其理解用户背景

### 自动注入

与知识库类似，配置环境变量后 `load_memory` 工具会被自动注入到 Agent 中。Agent 无需额外代码即可获得记忆能力。

## 记忆体与知识库的区别

| 特性 | 记忆体 | 知识库 |
|------|--------|--------|
| 数据来源 | Agent 对话产生 | 用户上传文档 |
| 数据范围 | 个人化、与用户相关 | 组织级、所有用户共享 |
| 更新方式 | Agent 自动保存 | 人工管理上传 |
| 检索方式 | 按用户 ID 隔离 | 全局检索 |
| 典型用途 | 记住用户偏好、历史 | 查询产品文档、FAQ |
