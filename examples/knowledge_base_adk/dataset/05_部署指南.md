# AgentEngine 部署指南

## 部署方式

AgentEngine 支持两种部署模式：

### 代码模式（Code Mode）

将 Python 代码和依赖打包为 zip 文件上传到金山云 Serverless 平台。

**优点**：打包快、冷启动快、适合轻量级 Agent
**限制**：不支持系统级依赖（如 C 扩展库）

```bash
agentengine build . --mode code --push
agentengine deploy . --target serverless
```

### 容器模式（Container Mode）

构建 Docker 镜像并推送到金山云容器镜像仓库。

**优点**：支持任意系统依赖、环境完全可控
**限制**：镜像较大、冷启动较慢

```bash
agentengine build . --mode container --push
agentengine deploy . --target serverless
```

### 一键部署（推荐）

使用 `launch` 命令自动完成构建和部署：

```bash
agentengine launch . --target serverless
```

## 部署前置条件

1. 配置金山云凭证：

```bash
export KSYUN_ACCESS_KEY=your_ak
export KSYUN_SECRET_KEY=your_sk
export KSYUN_ACCOUNT_ID=your_account_id
export KSYUN_REGION=cn-beijing-6
```

2. 确保项目中有 `agentengine.yaml` 或 `ksadk.yaml` 配置文件
3. 确保所有依赖在 `requirements.txt` 或 `pyproject.toml` 中声明

## 版本管理

AgentEngine 支持版本管理，方便回滚：

```bash
# 查看版本列表
agentengine version list --agent my_agent

# 回滚到指定版本
agentengine version rollback --agent my_agent --id version_id
```

## 部署后验证

```bash
# 查看部署状态
agentengine status --agent my_agent

# 远程调用测试
agentengine invoke --agent my_agent --message "你好"

# 销毁实例
agentengine destroy --agent my_agent
```

## 环境变量传递

部署时，`.env` 文件中的环境变量会自动传递到 Serverless 运行环境。知识库和记忆体的配置变量也会被正确传递，确保云端 Agent 具备与本地一致的能力。

## 常见问题

**Q: 部署后 Agent 无法访问知识库？**
A: 确认 Serverless 函数的网络配置允许访问 `aicp.api.ksyun.com`，并确认 AK/SK 环境变量已正确设置。

**Q: 冷启动时间太长？**
A: 推荐使用代码模式（Code Mode）部署，冷启动时间通常在 5-10 秒。容器模式可能需要 30 秒以上。

**Q: 如何查看运行日志？**
A: 使用 `agentengine status --agent my_agent` 查看实例状态，或在金山云控制台查看 Serverless 函数日志。
