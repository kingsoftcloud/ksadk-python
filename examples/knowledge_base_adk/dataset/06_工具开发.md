# Agent 工具开发指南

## 概述

工具（Tool）是 Agent 与外部世界交互的能力接口。通过为 Agent 添加工具，可以让它执行搜索、调用 API、操作数据库等操作。

## ADK 工具定义

在 Google ADK 框架中，工具就是普通的 Python 函数：

```python
def get_weather(city: str) -> dict:
    """查询指定城市的天气信息

    Args:
        city: 城市名称，例如 "北京"、"上海"

    Returns:
        包含天气信息的字典
    """
    # 调用天气 API
    return {
        "city": city,
        "temperature": "25°C",
        "weather": "晴",
        "humidity": "45%"
    }
```

**关键要求**：
- 函数必须有清晰的 docstring，这是 LLM 理解工具用途的关键
- 参数必须有类型注解
- 返回类型建议为 dict
- Args 部分要详细描述每个参数的含义和示例

## 注册工具到 Agent

```python
root_agent = Agent(
    name="weather_assistant",
    model=model,
    tools=[
        get_weather,
        get_forecast,
        get_air_quality,
    ],
)
```

## LangChain 工具定义

```python
from langchain_core.tools import tool

@tool
def search_database(query: str, table: str = "users") -> str:
    """搜索数据库

    Args:
        query: SQL 查询条件
        table: 数据表名称，默认为 users
    """
    # 执行查询
    return f"Found 10 results in {table}"
```

## MCP 工具集成

AgentEngine 支持通过 MCP（Model Context Protocol）接入外部工具服务：

```python
from google.adk.tools.mcp_tool import MCPToolset, StreamableHTTPConnectionParams

mcp_tool = MCPToolset(
    connection_params=StreamableHTTPConnectionParams(
        url="https://mcp-server.example.com",
        headers={"Authorization": "Bearer token"},
    )
)

root_agent = Agent(
    name="my_agent",
    model=model,
    tools=[local_tool, mcp_tool],
)
```

## 工具开发最佳实践

1. **单一职责**：每个工具只做一件事，保持简洁
2. **错误处理**：工具内部捕获异常，返回友好的错误信息
3. **描述清晰**：docstring 是 LLM 决定何时调用工具的唯一依据
4. **参数精简**：必要参数尽量少，可选参数给默认值
5. **返回结构化**：返回 dict 或格式化的字符串，便于 LLM 解析
