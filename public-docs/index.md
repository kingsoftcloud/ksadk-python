# KsADK

一次构建 Agent，到处运行。

KsADK 是面向 AI Agent 的运行时平台（Agent Runtime Platform）。继续使用 Google ADK、LangGraph、LangChain 或 DeepAgents 编写业务 Agent，再用 KsADK 获得统一的本地运行、浏览器调试、OpenAI-Compatible API、沙箱执行、部署和可观测体验。

[阅读文档 →](getting-started/quickstart.md){ .ksadk-cta }
[GitHub 仓库 ↗](https://github.com/kingsoftcloud/ksadk-python){ .ksadk-cta-secondary }

<div class="ksadk-install" markdown>

```bash
pip install -U "ksadk[all]"
```
